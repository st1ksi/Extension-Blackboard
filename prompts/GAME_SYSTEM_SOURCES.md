# Game profile source references

These are original condensed instructions for a model, not complete rulebooks or
programmatic implementations of six new games. Profiles select mechanics without
setting lore. Record the campaign's actual edition, printing, allowed supplements
and exceptions; public introductory rules do not replace absent full-source tables.

## Call of Cthulhu 7th Edition

- [Chaosium 7e Quick-Start](https://www.chaosium.com/cthulhu-quickstart/): introductory checks, skill development, bonus/penalty dice, Luck, Sanity and combat.
- [The Lightless Beacon, official PDF](https://www.chaosium.com/content/FreePDFs/WeAreAllUs/2019/The%20Lightless%20Beacon%20-%20Call%20of%20Cthulhu.pdf): optional Luck spending summary. Adventure content is not part of the profile.
- [Chaosium investigator-sheet guide](https://www.chaosium.com/40th-anniversary-investigator-sheets/): sheet and development references; Pulp options remain separate.
- [Chaosium Keeper Rulebook description](https://www.chaosium.com/call-of-cthulhu-keeper-rulebook-hardcover/): normal core scope is distinct from Quick-Start and Starter Set. Full-source procedures still require the adopted reference, not a claim that this extension contains the books.

For a new unspecified campaign the default is standard 7e core (Keeper Rulebook,
with Investigator Handbook material where applicable). An existing Quick-Start or
Starter Set scope is preserved. Public introductory checks do not silently narrow
the full profile, nor supply absent insanity, spell, injury or option details.
The UI description and ruleset explicitly disclose the closed-world Luck house
policy: creating a genuinely undefined external circumstance requires a scoped
campaign agreement; prepared facts and closed contents stay fixed. This is a
compatibility choice, not a statement that ordinary CoC forbids external Luck.

## Pathfinder Second Edition Remaster

- [Paizo Remaster preview](https://downloads.paizo.com/RemasterCorePreview.pdf): source/version distinctions.
- [Checks, Player Core on Archives of Nethys](https://2e.aonprd.com/Rules.aspx?ID=2278), [degrees of success](https://2e.aonprd.com/Rules.aspx?ID=2286), [actions](https://2e.aonprd.com/Rules.aspx?ID=2335) and [basic actions](https://2e.aonprd.com/Rules.aspx?ID=2343): authorized rules reference.
- [Incapacitation](https://2e.aonprd.com/Traits.aspx?ID=631), [leveling up](https://2e.aonprd.com/Rules.aspx?ID=2065) and [Make an Impression](https://2e.aonprd.com/Actions.aspx?ID=2392): effect authority, advancement and social limits.
- [Hero Points, Remaster Player Core p. 413](https://2e.aonprd.com/Rules.aspx?ID=2333): session lifecycle, keep-second fortune reroll and spend-all death prevention when dying would increase. The separate legacy start-of-turn wording is not added automatically.

Legacy material and optional progression rates require explicit adoption. Secret
rolls remain subject to actual host/tool disclosure capabilities; no invisible
receipt channel is promised.

## GURPS Fourth Edition

- [SJ Games GURPS Lite](https://www.sjgames.com/gurps/lite/) and [Fourth Edition Lite listing](https://warehouse23.com/products/gurps-lite-fourth-edition).
- [Publisher-hosted Fourth Edition Lite PDF](https://www.sjgames.com/ill/img/retailerimages/Munchkin%20OTD/Game%20Support/GURPS/GURPS_Lite_Fourth_Edition.pdf): 3d6 resolution, derived attributes, seconds, defenses, injury, FP and points.
- [Official Basic Set FAQ](https://www.sjgames.com/gurps/faq/FAQ4-3.html): contest margins, resistance exceptions, turn boundaries and defense details.

For a new unspecified campaign the profile uses Fourth Edition Basic Set
(Characters and Campaigns). Existing Lite or another explicitly adopted revision
is preserved. Additional options, magic, powers and cinematic rules require adopted
sources; the profile does not supply all catalogs, point costs or specialized combat
procedures. The publisher Lite PDF, p. 9, confirms Luck's 60/30/10-minute variants
use time of play. The profile distinguishes that resource cadence from world time
and requires an agreed substitute if asynchronous play cannot measure it reliably.

## Cyberpunk RED

- [R. Talsorian Edgerunner Folio](https://rtalsoriangames.com/wp-content/uploads/2024/07/RTG-CPR-DLC-Edgerunner-Folio.pdf): character statistics, checks, Luck, actions, ROF and ranges.
- [Official Core Book FAQ v1.3](https://rtalsoriangames.com/wp-content/uploads/2021/07/RTG-CPR-CoreBookFAQv1.3.pdf): exceptions, injuries, cyberware and NET access.
- [Publisher Gangs and Combat overview](https://rtalsoriangames.com/2020/10/29/cyberpunk-red-alert-gangs-and-combat/): combat distinctions.
- [Publisher Free Basic Rules on Roll20](https://roll20.net/compendium/cpunk/Playing%20the%20Game): shared time, wounds, Death Saves and stabilization.

RED core, its Jumpstart Kit, Cyberpunk 2020 and Edgerunners Mission Kit are not
silently interchangeable. Exact IP prices, advanced equipment, Roles, NET content
and optional systems require their governing source. Before NET resolution the
profile requires the adopted source's NET/Meat action-budget relationship and
rank budget to be recorded; tracking both does not grant extra actions. The direct
publisher either/or example in [Kitbashing Netrunning](https://rtalsoriangames.com/2019/07/05/kitbashing-netrunning/)
is explicitly Jumpstart material. The inspected full-core FAQ and Folio do not
state this relationship; this update therefore does not hardcode that example as
verified full-core RAW or invent a rank table from memory.

## Vampire: The Masquerade Fifth Edition

- [Paradox / World of Darkness Basic Mechanics](https://www.paradoxinteractive.com/games/world-of-darkness/news/vampire-the-masquerade-basic-mechanics) and [official free content](https://www.paradoxinteractive.com/games/world-of-darkness/community/free-content).
- [Licensed V5 Free Basic Rules on Roll20](https://roll20.net/compendium/vtm/BookIndex): [basic pools](https://roll20.net/compendium/vtm/Basic%20rolls), [criticals](https://roll20.net/compendium/vtm/Criticals), [Hunger](https://roll20.net/compendium/vtm/Hunger), [Willpower](https://roll20.net/compendium/vtm/Willpower) and [Rouse Checks](https://roll20.net/compendium/vtm/Rouse%20checks%20and%20using%20the%20Blood).
- [Conflict](https://roll20.net/compendium/vtm/Basic%20conflict), [damage](https://roll20.net/compendium/vtm/Damage), [Dominate](https://roll20.net/compendium/vtm/Dominate) and [Presence](https://roll20.net/compendium/vtm/Presence): system authority and scope.

The free introduction is not treated as the entire core book: full XP costs,
Humanity/Remorse and Blood Potency tables need the adopted source. Scenario-specific
recovery limits and simplified Blood Surge are not generalized to all chronicles.
Willpower recovery explicitly follows the adopted source's superficial/aggravated
triggers and session boundaries. No unverified full-core numerical recovery rate
has been added from an unofficial hosted book or from model memory.

## Savage Worlds Adventure Edition

- [Pinnacle SWADE Test Drive 2020](https://peg-swade.s3-us-west-2.amazonaws.com/SW_Test_Drive_2020.pdf): Traits, Aces, Wild Die, Bennies, initiative, harm and powers. Its setting/adventure is not included in the profile.
- [Pinnacle official SWADE implementation changelog](https://gitlab.com/peginc/swade/-/blob/master/CHANGELOG.md): implementation reference for edition/optional-rule distinctions.

Older Test Drives do not override changed SWADE rules. A dedicated deck engine is
not included: verifiable cards or a declared dice-indexed remaining-deck method are
required. Benny story influence needs an explicit scoped campaign agreement before
a dependent action; it is neither silently removed nor a blanket retcon permission.
The 2020 publisher Test Drive, rules p. 3, confirms ordinary session baselines:
three for a player Wild Card, a shared GM pool by number of player characters,
and two personal Bennies for each GM Wild Card. Existing setting/Edge exceptions
remain authoritative; entering view or a new model message never resets a pool.

## Boundaries common to the profiles

- Only the existing D&D advancement schema has a built-in calculator. Other systems'
  `MISC #character_progression` records remain model-maintained.
- Actual direct randomness requires real receipts. Authorized rerolls retain both
  results and costs; technical retry, audit and repair cannot invent or replay them.
- No-dice off-screen adjudication is a declared simulation convention distinct from
  official random resolution. Preparation budgets and horizons remain quality-owned.
- Local automated tests verify profile selection, exact composition, storage,
  schema routing, snapshots and UI, not mastery of every source rule by a real model.

Game names identify compatible rulesets. This extension is not affiliated with or
endorsed by their publishers. No source PDF, adventure, setting catalog or extracted
rulebook text is bundled with the extension.
